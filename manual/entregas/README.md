# Guías de entrega

> Generado por `manual/catalogo/gen-entregas.mjs`.

Cuando entra un pedido: abre la guía del producto, manda el email de datos, y cuando contesten pega el prompt con sus datos.

- **A · Un prompt:** 5–15 min de tu tiempo; se entrega el mismo día
- **B · Prompt + accesos del cliente:** 30–90 min de tu tiempo, casi todo esperando al cliente
- **C · Proyecto por fases:** 1–3 días de trabajo
